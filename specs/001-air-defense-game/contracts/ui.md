# UI Contract: 3D 防空守衛無限模式

## Input Contract

| Input | Context | Result |
|---|---|---|
| `W/A/S/D` | 遊戲中 | 玩家移動 |
| Mouse movement | 遊戲中 | 第一人稱視角轉向 |
| `E` | 可互動武器（額外操作） | 拾取武器；不可合法拾取時不改變狀態 |
| `G` | 玩家持有武器（額外操作） | 將目前武器丟到玩家附近；空手時無作用 |
| `1` | 物品欄第 1 格 | 直接裝備或切換防空炮，不受與場景武器距離限制；只在空襲階段生效 |
| `2` | 物品欄第 2 格 | 直接裝備或切換狙擊槍，不受與場景武器距離限制；只在地面戰階段生效 |
| Left mouse | 持有防空炮 | 僅在綠色穩定鎖定且不在冷卻時發射；其他情況不發射 |
| Left mouse | 持有狙擊槍 | 在不處於射擊冷卻時發射；有效命中立即擊倒敵人 |
| Right mouse | 持有狙擊槍 | 開啟或關閉狙擊瞄準視覺 |
| Start action | 主選單 | 點擊「開始遊戲」或按 `Enter`/`Space`，建立新局並進入空襲階段 |
| Quit action | 主選單 | 點擊「離開遊戲」或按 `Q`/`Escape`，關閉遊戲視窗並結束程式 |
| Return action | 失敗畫面 | 點擊「返回主選單」或按 `Enter`/`Escape`，清除本局並返回主選單 |

## Screen States

### Main Menu

- 顯示遊戲名稱「3D 防空守衛」。
- 提供可點擊的「開始遊戲」與「離開遊戲」按鈕，並保留鍵盤快捷操作。
- 不顯示上一局的可操作戰鬥物件。

### Airstrike HUD

- 畫面中央永遠顯示正方形瞄準框。
- **白框**：沒有有效鎖定目標。
- **紅框閃爍**：中心 ray 持續命中且未遮擋當前戰鬥機，但鎖定尚未滿 3 秒；紅框每 0.12 秒切換一次可見/不可見。
- **穩定綠框**：連續鎖定滿 3 秒，可以發射導引彈。
- 每個框色狀態 MUST 同時顯示文字或圖示：「未鎖定」、「鎖定中」或「可發射」；不能只依賴顏色。
- 顯示生命值、空襲警告、存活時間、擊落飛機數與擊倒敵人數。
- 畫面下方持續顯示兩格物品欄：`1 防空炮`、`2 狙擊槍`；目前選取欄位高亮，不適用當前階段的欄位變暗。
- 當預估撞樓時間小於或等於 8 秒時，顯示包含「空襲警告」文字或等義圖示的撞樓風險提示。

### Ground Combat HUD

- 顯示生命值、存活時間、擊落飛機數與擊倒敵人數。
- 顯示目前持有武器與兩格物品欄；玩家可按 `2` 直接切換狙擊槍。
- 若下一架飛機開始接近時玩家仍持有狙擊槍，顯示「物品欄按 1 切換防空炮」提示；不自動換槍。
- 狙擊瞄準時提供清楚的中心命中視覺，但不顯示不存在的彈藥數量。

### Game Over

- 顯示「飛機撞擊大樓」或「玩家生命值歸零」其中一個失敗原因。
- 顯示本局存活時間、擊落飛機數與擊倒敵人數。
- 提供返回主選單的操作；失敗畫面期間忽略射擊與移動輸入。

## Visual Semantics

- 顏色狀態必須搭配文字或圖示提示，避免只依賴顏色辨識；紅框狀態文字必須明確表示「鎖定中」。
- 紅色閃爍只表示鎖定進行中，不得讓玩家誤以為已可發射；閃爍半週期固定為 0.12 秒。
- 綠色必須是穩定、不閃爍的狀態，代表按下射擊鍵會觸發導引彈。
- 瞄準中斷時，瞄準框立即回到白色，並清除目前鎖定進度。
