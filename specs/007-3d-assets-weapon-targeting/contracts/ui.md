# UI 與輸入契約：3D 資產與武器瞄準整合

## 輸入契約

| 輸入 | 適用情境 | 結果 |
|---|---|---|
| `1` | 戰鬥中 | 選擇普通防空炮；若是從其他武器切換，清除多目標鎖定與非適用準心 |
| `2` | 戰鬥中 | 選擇狙擊槍，沿用既有狙擊鏡與射擊規則 |
| `3` | 戰鬥中 | 選擇手槍，顯示手槍樣式中央準心 |
| `4` | 已解鎖 RPG 的戰鬥中 | 選擇 RPG，顯示與手槍相同樣式的中央準心；不開啟狙擊鏡或防空鎖定模式 |
| `5` | 已解鎖多目標防空炮的戰鬥中 | 選擇多目標防空炮，顯示 2 倍普通白框；鎖定只在瞄準模式開啟後累積 |
| 右鍵按下 | 普通／多目標防空炮 | 開啟或關閉防空瞄準；關閉立即清除對應鎖定 UI，但不取消已發射的導彈 |
| 左鍵按下 | RPG | 僅在中心射線命中距離小於或等於 12.0 的地面敵人時建立爆炸；超距離、飛機、無彈藥或冷卻中皆無效果 |
| 左鍵按下 | 普通防空炮 | 沿用單一目標完整鎖定後建立一枚導引導彈 |
| 左鍵按下 | 多目標防空炮 | 僅在所有目前有效目標都完成鎖定時建立一次齊射；每個目標一枚導引導彈 |
| 武器切換／離開戰鬥／重置 | 所有戰鬥階段 | 隱藏上一個武器家族的準心、白框、鎖定進度與小準心 |

右鍵放開不另外觸發事件；防空炮的瞄準模式以右鍵按下切換。RPG 不與防空炮或狙擊槍
共享瞄準狀態。

## 新版／舊版防空介面

主選單的「設定」頁只保存本次程式啟動期間的顯示偏好，提供「新版防空瞄準」與
「舊版圓圈鎖定」以及「返回主選單」。重新啟動時預設為新版；此偏好不寫入 Profile，
也不得改變射程、傷害、鎖定 tracker、導彈或升級規則。

| 模式 | 普通防空炮開鏡時的顯示 | 多目標防空炮 |
|---|---|---|
| 新版 | 現行較大固定白框與新版動態準心／鎖定回饋 | 維持 2 倍白框與每目標動態小準心 |
| 舊版 | 恢復原始 003 的較大固定框、以敵機投影為中心的連續跟隨圓圈、進度條與狀態文字；圓圈由取得範圍依進度縮小到敵機外框 | 仍維持新版 2 倍白框與每目標動態小準心，不套用單一圓圈 |

舊版圓圈只在普通防空炮實際開鏡且有目標投影時可見；目標不可見時依鎖定狀態隱藏
或衰減，關閉開鏡、切換武器、離開戰鬥、波次／終止或返回主選單時清除。舊版與新版
共用同一個 15% 中央判定、3 秒鎖定、0.75 秒衰減與開火資格。

## 準心與白框契約

同一時間只允許一個武器準心家族可見：

| 武器 | 顯示內容 | 顏色／尺寸規則 |
|---|---|---|
| 手槍 | 中央十字準心 | 手槍既有樣式 |
| RPG | 中央十字準心 | 與手槍完全相同的樣式與尺寸 |
| 普通防空炮 | 固定白框；開啟瞄準後加單一動態鎖定標記 | 白框使用普通基準乘白框升級倍率 |
| 多目標防空炮 | 固定白框及每個敵機一個小準心／進度標記 | 白框為普通白框的 `AA_MULTI_LOCK_FRAME_MULTIPLIER`（2.0）倍；不顯示固定 2 或 6 目標容量 |
| 狙擊槍 | 既有狙擊鏡準心 | 不與其他家族重疊 |

多目標小準心的每個 `target_id` 必須位於其投影敵機位置，並以個別鎖定狀態反映：

- 白色：尚未鎖定或沒有進度。
- 紅色：正在累積或衰減，尚不可發射。
- 綠色：目前仍可見、仍在多目標白框內且已完成鎖定。

小準心旁的進度標記必須能區分各目標的獨立進度；當目標離框時保留衰減中的標記，
歸零、死亡或不可見後移除。沒有有效目標時不建立任何小準心。

## 多目標射擊閘門

1. 白框內的每架可見敵機都加入自己的鎖定狀態，不以固定數量截斷。
2. 只要任一目前有效目標尚未 READY、離開白框、不可見、死亡或不存在，左鍵就不產生任何導彈，也不設定冷卻。
3. 閘門通過時，畫面可觀察到 N 枚導引導彈同時建立，N 等於該次完整有效目標集合的數量。
4. 齊射後小準心與進度重設，下一次需要重新完成當時有效集合的全數鎖定。
5. 已建立的導彈只追蹤建立時保存的目標 ID；目標死亡或導彈過期只清除該枚，不轉鎖其他敵機。

## 生命週期契約

- 關閉防空瞄準、切換武器、進入下一波、game over、返回選單與重新開始時，白框以外的
  鎖定 UI 必須清除；普通與多目標的 tracker 不得殘留前一波資料。
- 關閉瞄準後，飛行中的導彈仍可繼續移動、命中或過期；進入終止／返回選單時則全部清除。
- RPG 爆炸、普通防空炮命中與多目標齊射都不能讓手槍、狙擊槍或其他準心短暫重疊。
- 商店只顯示有效的 `aa_whitebox` 白框大小升級；舊的多目標固定數量升級不可在 UI 中
  顯示為目標容量或可購買的有效規則。

## RPG 與陸地自動防禦射擊回饋

| 事件 | 可見結果 | 清理規則 |
|---|---|---|
| 合法 RPG 射擊 | 從玩家視角附近飛向爆炸中心的綠色長方體子彈，具有唯一 ID 與固定長寬 | 到達／過期、波次切換、終止或返回選單時移除；不重複套用爆炸 |
| 陸地自動防禦實際開火 | 可辨識的固定砲台與從砲台飛向敵人的黃色短暫曳光，樣式沿用敵方地面攻擊 | 曳光效果到期或場景清理時移除；不擁有傷害權責 |

陸地自動防禦只在 32.0 世界單位（包含邊界）內選擇已落地且存活的地面敵人，
基準每發傷害為 1、一般敵人為 3 HP、Boss 最多被自動防禦打掉 50% 最大生命值。
未升級發射間隔與手槍預設 CD `0.20` 秒相同；這些數值不在 HUD 顯示成可任意
調整的玩家設定。

手槍、RPG 與狙擊槍對地面人物使用中央準心射線時，瞄準碰撞箱必須與當前地面敵人的
可見外觀包絡相同：成功載入 OBJ 時覆蓋 5 倍可見模型的實際包絡，fallback 時覆蓋
fallback 本身的可見大小。這只影響中央準心的目標取得，不改變自動防禦的 32.0 射程、
武器傷害或人物生命值。
